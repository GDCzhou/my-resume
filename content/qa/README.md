## 面试优先级建议

- **必背**：04-事务一致性与幂等（含 Q1/Q2/Q3/Q4/Q5/Q6）、01-订单与支付体系（Q1/Q2/Q3/Q4/Q5）、03-秒杀（Q1/Q2）
- **高频**：02-团检（Q1/Q2/Q5）、06-导检（Q1/Q2/Q3）、05（Q1/Q6）
- **加分**：07-认证重构（Q4 五元组对拍）、06（Q7 RAG 精排副作用）

## 用法

1. 面试前按"必背 → 高频 → 加分"顺序过一遍
2. 每个 Q 先自己答，再看答案（答案里有面试要点提示）
3. 被追问细节时，答案里标注了代码位置（文件:行号），可以"我实现时在 XxxServiceImpl 的 Lxxx"佐证
