**项目简介**：面向体检中心到院现场的智能导检与排队叫号系统，替代人工喊号与纸质指引，自动规划每位体检者的检查路径与叫号时机。覆盖体检人 H5、医生叫号端、商显叫号屏、楼层大屏、管理后台五端；按真实分院场地建模（3 层楼 / 12 个检查节点），单分院日均千级人次。

**技术栈**：Java · Spring Boot · DDD 六边形架构 · Redis · MySQL · MQTT（EMQX）· Vue 3 · Android WebView · ArchUnit · Docker/K8s

**核心职责与成果**：

- **架构设计**：主导 DDD 六边形分层，领域层零框架依赖，Redis / MQTT / HTTP 经端口下沉适配层；所有状态变更在单线程事件循环串行执行，从根上消除排队与号位竞态；ArchUnit 固化 11 条分层红线，全量单测 373 条、算法核心 61 项用例与 Python 仿真逐位对拍。
- **调度引擎**：将体检套餐建模为带前置依赖的任务 DAG，用「预计完工时间」替代「按队伍长度」选房间，解决彩超排长队、心电图空转的资源错配；自建策略对照仿真（300 人/组 × 10 组随机种子），相比纯挑短队基线平均等待降低 4.6%、在院时长缩短 4.4%，9/10 组占优。

- **异常自愈**：30 秒巡查识别「末项超时 / 做完忘点 / 医生离岗」三类异常，自动软淡化、漏点回收、失败率熔断（超 0.6 跳闸、16 分钟冷却半开），过号休眠保位、熔断自动重导备用房间，现场无人盯屏。
- **多端推送**：MQTT（EMQX）推送叫号帧（retained + QoS1，断线重连不丢最后一帧）；设备零账号接入，bootstrap 下发 2 小时 HMAC 短期密码，长期密钥只走 HTTPS。
- **老系统替换**：老导检系统 20 个控制器 / 163 个接口原样兼容为契约层，接口治理后置以控制变更爆炸半径，任一步可回滚可复盘。

**项目简介**：面向体检中心报告解读场景的 RAG 智能解读系统，由 Python 检索增强服务与 Java Spring AI 生成服务构成，实现从知识库检索到报告解读的端到端链路，支撑综合解读、多学科解读与历年纵向对比。

**技术栈**：Python（FastAPI）· Qdrant · Java · Spring Boot · Spring AI

**核心职责与成果**：

- **知识库建设**：主导体检文档解析、切分与向量化入库，重复入库幂等，支持知识库增量更新。
- **检索质量优化**：设计「宽召回（top-20）+ cross-encoder 精排」两段式检索，黄金集 A/B 实测 context precision 由 0.323 提升到 0.369（+14%）；定位重排副作用——出处命中@1 由 100% 降到 92.3%，根因是拒答阈值未按 cross-encoder 校准并修复。
- **评测可信度**：用 Wilson 95% 置信区间而非点估计，并标注 n=16 下 ±25% 误差；用语言切片量化跨语言偏置（中文 top1 0.689 / 英文 0.546）。
- **医学可信治理**：临床规则图谱 + 证据溯源 + 拒答机制，资料不足明确拒答，约束模型幻觉。

### 登录认证服务 DDD 重构

**项目简介**：旧认证服务由 560 行上帝类 SysLoginService 扛下 9 种登录方式，一个方法混入校验、调远端、写 Redis、审计、签 token 五件事，且缺少失败锁号等防暴力破解机制（P0 安全漏洞）；主导 DDD 分层重构，零中断迁移。

**技术栈**：Java · Spring Boot · Spring Cloud Alibaba · Redis · JWT · ArchUnit

**核心职责与成果**：

- 将上帝类拆分为分层 + 9 个登录适配器，新增登录方式只需加一个适配器，迁移零中断。
- 失败 5 次锁号 30 分钟、3 次强制验证码等规则收进聚合根 LoginAttempt，改锁号时长只改一个常量、规则可单测。
- 端口倒置，业务层定义接口，Redis / Feign / 签 token 全部下沉适配层，换 Redis 只换一个实现类、业务零感知。
- 重构中补齐失败锁号、密码明文等 P0 安全漏洞；分层红线固化进 CI（ArchUnit），防止架构回退。
