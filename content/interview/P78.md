# P78 什么是零拷贝？零拷贝如何减少 CPU 拷贝与上下文切换？

> 本集与 P76 内容重复（同一主题的重复投稿），完整笔记见 [P76](P76.md)。

## 速记

- 零拷贝 = 减少 CPU 参与的数据拷贝和用户态/内核态切换；
- 手段：`mmap`（省一次用户态拷贝）、`sendfile`（内核内直达）、`sendfile + DMA gather`（CPU 零拷贝）；
- Java 里 `FileChannel.transferTo`（NIO），Netty FileRegion、Kafka/RocketMQ 都用它；
- 本质不是"0 拷贝"，而是让 DMA 搬数据、CPU 只传元数据。
