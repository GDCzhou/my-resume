# P77 什么是 WebSocket？Nginx 如何支持 WebSocket 协议？

> 本集与 P75 内容重复（同一主题的重复投稿），完整笔记见 [P75](/java/P75)。

## 速记

- WebSocket 是基于 TCP 的全双工长连接协议，握手复用 HTTP（`Upgrade: websocket`）；
- 服务端可主动推送，适合聊天、弹幕、实时大屏；
- Nginx 支持要点：透传 `Upgrade` 和 `Connection: upgrade` 头、`proxy_http_version 1.1`、调大 `proxy_read_timeout`；
- 注意长连接的连接数、心跳、集群下的节点路由（Redis/MQ 广播）。
