### 登录认证服务 DDD 重构（healthy-auth → healthy-auth-v2）

**项目简介**：对承载 9 种登录方式、22 个接口的旧认证服务进行 DDD 分层重构，采用绞杀者模式渐进替换，实现零中断迁移。

**技术栈**：Java 21 · Spring Boot 3.4 · Spring Cloud Alibaba · Nacos · Redis · JWT · ArchUnit

**核心职责**：

- 将 560 行承载 9 种登录职责的上帝类重构为 DDD 五层架构，拆分 9 个单一职责登录适配器（新增登录方式只需新增一个 Adapter），Redis / Feign / JWT 实现全部下沉端口。
- 事件风暴建模落地充血模型（聚合根 LoginAttempt），"失败 ≥5 次锁号 30 分钟"等业务规则收进聚合方法（Tell-Don't-Ask）。
- 设计防腐层（ACL）隔离外部系统：外部 DTO 与内部领域模型物理分离，边界翻译并丢弃密码等敏感字段，落地"Feign Client + Mapper + Adapter"三件套。
- 设计 StepPipeline 用例编排引擎：以自定义 Pipeline 编排登录用例（校验输入 → 锁号检查 → 身份识别 → 签发 Token → 写会话），业务决策与技术动作在 step 层显式分离。
- ArchUnit 架构约束固化进 CI（11 条结构规则 + 5 条 DDD 规则），分层依赖方向固化为可执行红线；重构补齐失败锁号机制等 P0 安全漏洞。
