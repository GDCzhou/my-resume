**技术栈**：Java · Spring Boot · Spring Cloud Alibaba（Nacos）· MySQL · Redis · MQTT(EMQX) · Vue 3 · Android WebView · PySide6 · ArchUnit · Docker/K8s

**核心职责**：

- **架构与并发模型**：主导从 0 到 1 的 DDD 六边形分层设计，领域层零框架依赖，Redis / MQTT / HTTP 经端口下沉适配层；所有状态变更在单线程事件循环串行执行，从根上消除排队与号位竞态，快照写 Redis 重启自动恢复；ArchUnit 固化分层红线，全量单测 **373 条**、算法核 **61 项**用例与 Python 仿真逐位对拍。

### 体检报告智能解读系统（RAG）

**项目简介**：面向体检中心报告解读场景的 RAG 智能解读系统，由 Python 检索增强服务与 Java Spring AI 生成服务构成，实现从知识库检索到报告解读的端到端链路，支撑综合解读、多学科解读与历年纵向对比。

**技术栈**：Python(FastAPI) · Qdrant · Java · Spring Boot · Spring AI

**核心职责**：

- **知识库建设**：主导体检文档解析、切分与向量化入库，重复入库幂等，支持知识库增量更新。
- **检索质量保障**：设计"宽召回（top-20）+ cross-encoder 精排"两段式检索，黄金集 A/B 实测 context precision 由 **0.323 提升到 0.369（+14%）**；同批暴露重排副作用——出处命中@1 由 100% 降到 **92.3%**，定位根因是拒答阈值沿用 bge cosine 标尺未按 cross-encoder 校准。
- **指标可信度**：评测用 **Wilson 95% 置信区间**而非点估计，并标注 n=16 下 ±25% 误差；用语言切片量化跨语言偏置（中文 top1 0.689 / 英文 0.546）。
- **检索生成打通**：检索证据经接口注入生成链路，故障自动降级，端到端链路实测跑通。
- **医学可信治理**：临床规则图谱 + 证据溯源 + 拒答机制，资料不足明确拒答，约束**模型幻觉**。
- **多模型调度与安全**：统一接入多模型并按优先级自动降级，按次核算 token 用量与成本；知识库全本地可内网部署，外部模型调用前实施数据脱敏。

### 登录认证服务 DDD 重构

**项目简介**：旧认证服务由 **560 行**上帝类 SysLoginService 扛下 **9 种登录方式**，一个登录方法混入校验、调远端、写 Redis、审计、签 token 五件事，业务规则与技术纠缠，且缺少失败锁号等防暴力破解机制（**P0 安全漏洞**）；主导 DDD 分层重构，**零中断迁移**。

**技术栈**：Java · Spring Boot · Spring Cloud Alibaba · Nacos · Redis · JWT · ArchUnit

**核心职责**：

- **架构升级**：主导 9 种登录方式的 DDD 重构，上帝类拆为分层 + **9 个登录适配器**，新增登录方式只需加一个适配器，迁移**零中断**。
- **业务规则归位**：失败 5 次锁号 30 分钟、3 次强制验证码等规则收进聚合根 LoginAttempt，改锁号时长只改一个常量、规则可单测。
- **技术解耦**：端口倒置，业务层定义接口，Redis / Feign / 签 token 全部下沉适配层，换 Redis 只换一个实现类、业务零感知。
- **安全与架构治理**：重构中补齐失败锁号、密码明文等 **P0 安全漏洞**；分层红线固化进 CI（ArchUnit），防止架构回退。
